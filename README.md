# Express Api skeleton

A production-ready backend template built with Express, TypeScript, and Mongoose. Features functional error handling using Result types and pattern matching for a type-safe, exception-free architecture.

## 🚀 Features

- **TypeScript** - Type-safe development
- **Express.js** - Fast, unopinionated web framework
- **Mongoose** - MongoDB object modeling
- **Functional Error Handling** - Use byethrow @praha/byethrow 
- **Pattern Matching** - Type-safe error routing with `ts-pattern`
- **Custom Exception Classes** - Structured error types with literal status codes
- **Validation** - Request validation pipeline with Result composition zod
- **Clean Architecture** - Organized by handlers, services, models, and routes
